- JSON 解析、两份清单名称/版本/技能路径一致、空 hooks、UI 字段长度及默认提示包含技能名均通过。
- 包内 Markdown 相对链接、引用文件存在及路径不逃逸检查；Skill 内无固定用户路径、业务仓库名或真实线程ID。
- 个人技能入口为指向完整源目录的符号链接，已读回 SKILL.md 与 handoff 模块；搬走源目录会导致该入口失效，迁移时应重装完整技能目录。

这是结构检查，不是插件平台的完整 schema/商店审核。压缩包的 ZIP CRC、17份文件清单及逐文件内容一致性检查均已通过；安装入口再次运行技能校验也通过。
